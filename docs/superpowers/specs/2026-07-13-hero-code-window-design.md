# Hero 코드 창 비주얼 디자인

## 목표

중앙 정렬된 Hero 텍스트의 가독성을 유지하면서, 우측 하단의 정적 다크 코드 창과 메탈릭 그린 브래킷으로 개발자 포트폴리오의 시각적 정체성을 강화한다.

## 배치

- Hero 텍스트는 화면 중앙 정렬을 유지하고, 모든 비주얼보다 높은 레이어에 둔다.
- 다크 코드 창은 Hero 우측 하단에 크게 배치하며, 오른쪽과 아래 약 30%가 Hero 영역 밖으로 잘린다.
- 코드 창은 정적인 React 소개 코드 스니펫과 macOS 스타일 제어 버튼을 표시한다.
- 3D 브래킷은 코드 창의 왼쪽 아래 모서리 앞 레이어에 겹치고 은은하게 부유한다.
- 모바일(760px 이하)에서는 코드 창과 브래킷을 숨긴다.

## 시각 기준

- 코드 창은 어두운 배경, 둥근 모서리, 그림자로 배경 위에 떠 있는 느낌을 만든다.
- 브래킷과 녹색 글로우는 코드 창보다 앞에 두고 텍스트를 가리지 않는다.
- `prefers-reduced-motion`에서는 브래킷 부유 애니메이션을 중지한다.

## 검증

- Hero 테스트에서 코드 창과 브래킷 이미지가 렌더링되는지 확인한다.
- 전체 테스트와 프로덕션 빌드가 통과해야 한다.

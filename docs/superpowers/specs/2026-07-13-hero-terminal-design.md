# Hero 터미널 비주얼 설계

## 목표

포트폴리오 첫 화면을 좌측 소개 문구와 우측 개발자 터미널 비주얼의 2열 구성으로 바꿉니다. 터미널에는 한 번 실행되는 타이핑 효과를 넣고, 메탈릭 그린 유리 질감의 3D 브래킷 PNG를 장식 요소로 배치합니다.

## 화면 구성

- 데스크톱에서 기존 인사말, 이름, 소개 문구, 스크롤 버튼은 좌측에 유지합니다.
- 우측에는 macOS 스타일 빨강·노랑·초록 제어 버튼이 있는 다크 터미널 창을 배치합니다.
- 터미널은 고정폭 글꼴을 사용하며, 그림자와 둥근 모서리로 배경에서 떠 보이게 만듭니다.
- 브래킷 PNG는 터미널 우측 하단에 일부 겹치게 두고, 녹색 계열 글로우와 느린 부유 애니메이션을 적용합니다.

## 터미널 동작

1. `> console.log("안녕하세요! 박재서입니다. :)");`를 자연스러운 속도로 한 번 타이핑합니다.
2. 입력 완료 후 0.5초 기다립니다.
3. 다음 줄에 `-> 안녕하세요! 박재서입니다. :)`를 표시합니다.
4. 완료된 줄 끝에 깜빡이는 커서를 유지합니다.

새 타이핑 라이브러리는 추가하지 않고 React 상태와 타이머로 구현합니다.

## PNG 에셋

- 프로젝트 내부의 `public/assets`에 투명 PNG로 저장합니다.
- 메탈릭 그린과 반투명 유리 질감의 3D `{ }` 브래킷 한 쌍으로 생성합니다.
- 텍스트, 로고, 그림자, 배경을 포함하지 않습니다.
- 터미널보다 앞에 보이되 본문 텍스트를 가리지 않는 크기와 배치로 사용합니다.

## 반응형 및 접근성

- 태블릿 이하에서는 Hero를 세로 배치합니다.
- 모바일에서는 브래킷 PNG를 숨기고 터미널의 폭·패딩·글자 크기를 줄입니다.
- `prefers-reduced-motion: reduce` 환경에서는 타이핑과 부유 애니메이션을 중지하고, 완성된 터미널 문구를 바로 표시합니다.

## 완료 기준

- 데스크톱에서 첫 화면 우측에 터미널과 브래킷 PNG가 보입니다.
- 타이핑은 한 번만 실행되고 출력과 커서가 남습니다.
- 모바일에서 가로 넘침 없이 Hero가 표시되고 브래킷 PNG는 보이지 않습니다.
- 기존 Hero의 인사말, 스크롤 버튼과 접근 가능한 페이지 구조를 유지합니다.

# 프로젝트 상세 모달 접근성 설계

## 목표

프로젝트 상세 모달을 키보드와 스크린리더로 예측 가능하게 사용할 수 있도록 만든다. 시각적 레이아웃과 프로젝트 상세 내용은 바꾸지 않는다.

## 동작

- 프로젝트 상세를 열면 닫기 버튼에 포커스를 둔다.
- 모달이 열린 동안 `Escape` 키는 모달을 닫는다.
- `Tab`과 `Shift+Tab`은 모달 안의 포커스 가능한 요소 사이에서 순환하며 배경으로 이동하지 않는다.
- 모달이 열려 있는 동안 `body` 스크롤을 잠그고, 닫을 때 기존 `overflow` 값을 복원한다.
- 닫을 때 모달을 열었던 프로젝트 버튼으로 포커스를 되돌린다.
- 기존의 상세 닫기 버튼과 스크롤 위치 복원 동작은 유지한다.

## 구현 경계

- `App`은 모달을 연 버튼 요소를 ref로 저장하고, 닫힌 뒤 해당 요소로 포커스를 복원한다.
- `ProjectDetail`은 초기 포커스, Escape 처리, 포커스 트랩, body 스크롤 잠금을 담당한다.
- 새 접근성 라이브러리는 추가하지 않는다.

## 테스트

- 모달을 열면 닫기 버튼이 활성 요소가 된다.
- Escape를 누르면 모달이 닫히고 시작 버튼에 포커스가 돌아온다.
- 첫 포커스 요소에서 Shift+Tab을 누르면 마지막 요소로, 마지막 요소에서 Tab을 누르면 첫 요소로 이동한다.
- 모달이 열릴 때 body 스크롤이 잠기고 닫을 때 복원된다.

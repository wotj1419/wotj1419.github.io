# Hero 브래킷 오버랩 디자인

## 목표

첫 화면의 기존 텍스트 위치는 유지하면서, 메탈릭 그린 3D 브래킷을 텍스트 뒤 레이어에 배치해 제목 주변에 깊이감 있는 시각적 포인트를 만든다.

## 레이아웃

- Hero의 텍스트 콘텐츠는 현재의 왼쪽 시작 위치와 너비를 유지한다.
- 별도 우측 컬럼을 제거하고, 브래킷 비주얼을 Hero 레이아웃 안에서 절대 위치로 배치한다.
- 브래킷은 `박재서입니다.` 제목의 오른쪽 뒤에서 일부 겹치게 두되, 본문과 인사 문구는 가리지 않는다.
- 텍스트 콘텐츠는 브래킷보다 높은 쌓임 순서를 갖는다.

## 시각·접근성 기준

- 기존 녹색 글로우, 그림자, 부유 애니메이션을 유지한다.
- 브래킷은 장식용 요소로 취급하고 포인터 이벤트를 받지 않는다.
- 모바일(760px 이하)에서는 기존과 같이 브래킷을 숨겨 텍스트 가독성을 우선한다.
- `prefers-reduced-motion`에서는 브래킷 부유 애니메이션을 중지한다.

## 검증

- Hero 렌더링 테스트에서 브래킷 이미지가 유지되는지 확인한다.
- 전체 테스트와 프로덕션 빌드가 통과해야 한다.
